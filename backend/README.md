# Backend (`backend/`)

This directory contains the server-side application logic, database integrations, and core services.

## Recommended Structure
- `src/`: Backend source code
  - `controllers/`: Request handlers and route controllers
  - `models/`: Data models and database schemas
  - `services/`: Business logic and third-party integrations
  - `middlewares/`: Authentication, logging, error handling
  - `config/`: Server and database configuration
