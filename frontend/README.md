# Frontend (`frontend/`)

This directory contains the user interface and client-side web application.

## Recommended Structure
- `src/`: Core application source code
  - `components/`: Modular UI components
  - `pages/` or `views/`: Application views and route handlers
  - `styles/`: Global stylesheets and CSS tokens
  - `services/`: API clients and service adapters
  - `hooks/` / `store/`: State management
- `public/`: Static assets (images, icons, fonts)
